# slither.clase

Versión simple de slither.io hecha con HTML, CSS y JavaScript, sin dependencias ni compilación.

## Cómo jugar

- **Computador:** mueve el mouse para girar; mantén clic izquierdo o la barra espaciadora para acelerar.
- **Celular:** toca la pantalla para girar; mantén el botón **Turbo** para acelerar.
- Come los puntos para crecer. Si tu cabeza choca con otra serpiente pierdes, y también si tocas el borde rojo.
